# Go 命令行图书借阅系统

## 1. 项目目标

编写一个在终端运行的图书借阅系统，管理图书的添加、查找、借出、归还和删除。

通过一个连续的小项目，巩固结构体、切片、Map、函数、指针、方法、错误处理，以及 Go 模块和包的组织方式。不追求复杂界面和功能数量，重点是能独立完成需求、解释数据如何变化，并验证异常情况。

## 2. 功能范围

### 必做功能

| 功能 | 具体行为 | 异常情况 |
| --- | --- | --- |
| 添加图书 | 输入编号和书名，新增图书，初始为未借出 | 拒绝空编号、空书名、重复编号 |
| 查看图书 | 显示编号、书名和借阅状态，按编号排序 | 空书库显示提示 |
| 查找图书 | 按编号查找一本书 | 明确提示不存在 |
| 筛选可借图书 | 列出所有未借出的图书 | 没有可借图书时显示提示 |
| 借出图书 | 将指定图书设为已借出 | 不存在或已借出时返回错误 |
| 归还图书 | 将指定图书设为未借出 | 不存在或未借出时返回错误 |
| 删除图书 | 按编号删除 | 不存在或已借出时返回错误 |
| 退出程序 | 正常结束菜单循环 | 非法菜单输入不应导致崩溃 |

### 选做功能

- 将图书列表保存到本地 JSON 文件，重新启动后可以读取。
- 按书名关键词搜索。
- 统计图书总数、已借出数量和可借数量。

第一版不做用户登录、借阅人管理、数据库、网页、并发和网络接口。内存版退出后数据会丢失，完成 JSON 保存后才具备持久化能力。

## 3. 使用的技术

只使用 Go 标准库，不需要第三方依赖。

| 技术或工具 | 用途 |
| --- | --- |
| Go Module / go.mod | 标识模块，声明 Go 版本和管理依赖 |
| fmt | 打印菜单和操作结果 |
| bufio、os | 读取终端输入；选做文件读写 |
| strings | 去除输入首尾空白，进行关键词匹配 |
| sort | 对图书列表排序，避免 Map 遍历顺序不固定 |
| errors 或 fmt.Errorf | 表达业务失败原因 |
| testing | 编写业务逻辑测试 |
| encoding/json（选做） | 编码和解码本地图书数据 |

终端输入建议统一使用一个 bufio.Scanner 按行读取，以支持包含空格的书名。读取结束时检查 Scanner.Err，并在输入结束时退出，避免无限打印菜单。

## 4. 数据设计

```go
type Book struct {
    ID       string
    Title    string
    Borrowed bool
}

type Library struct {
    books map[string]Book
}
```

- ID：唯一编号，例如 B001；去除首尾空白后不能为空，第一版区分大小写。
- Title：书名；去除首尾空白后不能为空。
- Borrowed：true 表示已借出，false 表示可借。
- books：键为图书编号，值为图书数据；通过构造函数初始化 Map。

练习顺序：先用 []Book 完成展示与筛选，再改为 map[string]Book 完成按编号管理。最后用一个小实验比较 map[string]*Book，暂时不必把整个项目改成指针 Map。

重点观察：

```go
book := books["B001"]
book.Borrowed = true
```

这里修改的是取出的结构体副本。使用 map[string]Book 时，要将修改后的 book 写回 Map。查找时使用 book, ok := books[id]，区分不存在与合法零值。

## 5. 建议的函数和方法

以下只列签名，按任务逐个实现：

```go
func NewLibrary() *Library
func (l *Library) Add(book Book) error
func (l *Library) List() []Book
func (l *Library) Available() []Book
func (l *Library) Find(id string) (Book, bool)
func (l *Library) Borrow(id string) error
func (l *Library) Return(id string) error
func (l *Library) Delete(id string) error
```

- NewLibrary 初始化内部 Map，调用方通过它创建可用的书库。
- Add 只接受初始未借出的图书；若传入 Borrowed 为 true，返回错误。
- List 返回按编号排序的图书切片，Available 采用相同排序规则。
- Find 返回图书副本和是否存在的标记。
- 借还、删除等业务方法返回 error，由菜单决定如何向用户显示。
- 业务方法不读取终端输入、不直接打印，以便复用和测试。

统一使用 *Library 接收者便于理解。注意：Go 参数传递都是值传递；本例已初始化的 Map 即使通过结构体副本访问，也可能修改共享的底层数据，不能简单认为“值接收者一定改不了 Map”。

## 7. 项目目录与运行方式

建议先建立一个独立练习目录和模块：

```text
library/
  go.mod
  main.go
  library.go
  library_test.go
  storage.go          # 选做：JSON 保存与读取
```

在 library 目录执行：

```bash
go mod init example.com/library
```

example.com/library 是练习用模块路径，不需要真的创建网站。go.mod 中的 Go 版本由本机工具生成。

所有 Go 文件使用 package main；整个包只定义一个 func main()，放在 main.go。其他文件保存类型、方法和测试，无须互相导入文件。

```bash
go run .        # 编译并运行当前包
go test ./...   # 执行当前模块内的包测试
go build .      # 构建可执行文件
```

library_test.go 只在测试时参与，不会编入普通的可执行程序。go run main.go 只选择一个文件，无法自动包含 library.go 中的定义。

## 8. 一周弹性学习安排

每个任务块约 30～60 分钟。按顺序推进，不要求连续学习；当天没完成，下次接着做，不重新开始。

### 任务一：展示与筛选

预置三本图书，其中一本已借出。用切片打印列表，实现返回可借图书的函数。

验收：空列表不崩溃；筛选不会改变原图书的状态。

### 任务二：添加与查找

引入 Library 和 Map，实现构造、添加和按编号查找。先在 main 中直接调用方法，不写菜单。

验收：空编号、空书名、重复编号均被拒绝；不存在的编号返回 false。

### 任务三：借出与归还

实现状态更新，观察“取出副本、修改、写回”的过程。

验收：连续借同一本书时第二次失败；归还后可再次借出；失败操作不改变书库。

### 任务四：删除与测试

实现删除，并使用 testing 为主要业务编写测试。每个测试创建独立书库，避免状态相互影响。

验收：已借出图书不能删除；未借出图书可以删除；删除后查找不到。

### 任务五：菜单与整理

为已有方法接上菜单，处理无效输入和输入结束。整理文件，运行测试和构建。

验收：按 README 或本说明即可启动；操作失败后还能继续选择其他菜单。

有余力再加 JSON。文件不存在可视为首次运行；JSON 损坏应报告错误，不要直接覆盖原文件。通过测试或临时目录验证保存再读取后数据一致。

## 9. 最低测试清单

- 添加有效图书成功，重复添加失败。
- 空编号和空书名添加失败。
- 查询不存在的编号返回 false。
- 首次借出成功，重复借出失败。
- 未借出的图书不能归还，归还后能再次借出。
- 已借出的图书不能删除。
- 空书库的列表和筛选正常返回空结果。
- 列表按编号排序，不依赖 Map 遍历顺序。
